02 / Studio

How the work gets made

I work the way an editor works: decide what the page is arguing, cut everything that does not argue it, then set the type. Interfaces are the same problem with more states.

Most projects arrive as a design question and leave as a codebase, so I keep both in the same hands. That removes the translation layer where intent usually goes missing.
